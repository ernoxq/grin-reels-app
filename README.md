# GRIN Reels

Монтаж рилсов «человек говорит в камеру» за 2–4 минуты: паузы и неудачные дубли вырезаны, субтитры по словам, заголовок, вставки в ритм, единый цвет, кнопка в конце. Монтирует программа на твоём компьютере — без облака, без водяных знаков, без платы за ролик.

## Установка на Mac (один раз, ~20 минут)

1. Нажми зелёную кнопку **Code → Download ZIP** и распакуй архив в папку «Домой».
2. Открой **Terminal**, напечатай `bash ` (с пробелом), перетащи в окно файл `install.sh` и нажми Enter.
3. Дождись надписи «Готово!». Приложение **GRIN Reels** откроется само и появится в Launchpad — его можно перетащить в Dock.

Дальше просто открывай **GRIN Reels** как обычное приложение: перетащи видео → «Собрать рилс». Готовый ролик сохраняется в «Фильмы → GRIN Reels».

## С iPhone

Пока приложение открыто на Mac, телефон в той же Wi-Fi может открыть ту же страницу: в Safari набери адрес, который показан при запуске (вида `http://192.168.x.x:8765`), затем **Поделиться → На экран «Домой»** — появится иконка GRIN Reels, открывается во весь экран.

## Windows (бета)

Распакуй архив → правый клик по `install.ps1` → **Run with PowerShell**. Затем запускай `Запустить GRIN Reels.bat`.

## Через Claude

Скил `skills/grin-reel-auto-edit.zip` устанавливается в Claude: **Customize → Skills → + → Upload a skill**. После этого ролики собираются прямо в чате, с любого устройства.

## Что умеет

- Вырезает паузы и неудачные дубли, оставляет лучшие.
- Субтитры фразами или по словам (с подсветкой слова и плашкой).
- Стиль по чужому ролику: перетащи готовый рилс — программа возьмёт темп монтажа, цвет и чёрно-белые вставки.
- Текст никогда не попадает под кнопки Instagram, TikTok и Shorts и не закрывает лицо.
- 20 бесплатных шрифтов с кириллицей (Playfair, Cormorant, Jost, Manrope, Prata, Lobster…) и готовые пары.
- 61 иконка GRIN для монтажа и призывов — любого цвета, в кружке или на плашке с надписью.
- 12 понятных пресетов цвета («Тёплый вечер», «Плёнка», «Кино: бирюза и оранжевый»…), авто-точка белого и ползунки тепла, яркости, контраста, насыщенности.
- Свои шрифты, музыка, стикеры и LUT — во вкладке «Мои файлы».
